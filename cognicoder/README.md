# CogniCoder Platform Module

**CogniCoder** is a live code learning, lab experiment evaluation, and AI-assisted programming studio.

## Folder Contents
- `index.html` — Full responsive CogniCoder application with 4-step progressive card navigation, interactive code studio, live test case runner, stop-watch timer, terminal stdout/stderr engine, and AI Sensei.
- `cognicoder-ai-logo.png` — Atomic orbital AI logo.
- `vfx-styles.css` & `vfx-engine.js` — VFX background animation system.

## Key Capabilities
1. **Curriculum Levels**: 10th Grade, Intermediate, B.Tech 1st Year, B.Tech 2nd Year, and B.Tech 3rd Year.
2. **Custom Course Codes**: `CC-DBMS-201`, `CC-DSA-202`, `CC-PROG-101`, `CC-JAVA-301`, `CC-PYTH-102`, `CC-LOGIC-001`.
3. **Live Test Engine**: Evaluates code against requirements, shows sequential green ticks (`✓`) or red crosses (`✗`), and features click-to-expand diagnostics with actionable hints.
4. **Execution Terminal**: Real-time compilation and execution logs with exit code feedback.
5. **Code Persistence**: Retains user code across experiments and page visits.
6. **Mobile Responsive**: Adapts across mobile, tablet, and desktop viewports.
